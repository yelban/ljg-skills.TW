# 約束引擎

輸入一個領域、一門專業、一個角色，找出框住它的那幾條約束，看清這組約束框出的解空間——以及這個解空間怎麼解釋它的種種行為。

## Workflow Routing

| Trigger | Workflow |
|---|---|
| 給領域、專業、角色、產品找本質約束 | 執行本文工序，寫成一篇中文散文分析，儲存為 Markdown 檔案 |
| 分析一場方案爭論為什麼說不清 | 先找各方預設約束，再說明他們其實是不是同一道題 |
| 判斷某條邊界是真硬約束還是舊解釋 | 走三層硬度和真偽定性，不急著給突破方案 |

## Gotchas

- 不要把約束寫成普通困難、缺點或建議。約束必須能改變解空間；拿掉它，允許的行為會變。
- 不要只盯目標。同一目標在不同約束下不是同一道題；先補全題面，再談解法。
- 不要把共識、習慣、行業話術順手歸進硬約束。硬約束要經得起"違背它是否立刻崩"這一問。
- 不要急著寫"如何突破約束"。先把當前約束的真實硬度、身份邊界和行為解釋力寫準，鬆動只在結尾點一句。
- 不要把身份約束和策略約束混在一起。拿掉之後還成其為自己的，不是身份約束。

## Examples

**Example 1: 分析一個角色**
```
User: "投資經理的約束是什麼？"
-> 找出資金期限、LP 信任、資訊不對稱、上行/下行分配等約束
-> 說明這些約束如何逼出追熱點、重共識、怕錯過等行為
-> 寫入 notes 裡的 Markdown 檔案
```

**Example 2: 分析一場爭論**
```
User: "為什麼產品和增長總吵架？"
-> 先拆出雙方預設約束：不能打擾使用者 vs 必須提高轉化
-> 說明目標看似都是做好產品，其實題面不同
-> 再解釋各自方案為什麼在各自約束裡是理性的
```

**Example 3: 判斷舊解釋**
```
User: "這個行業必須重銷售嗎？"
-> 先問這是世界約束、規則約束，還是行業解釋
-> 查有沒有別的時代、地區、玩家已經活著跨過去
-> 若跨過去仍成立，把它降級為軟約束或自設約束
```

## 約束是什麼

日常語感裡，約束是負面的——束縛、不自由、不能做什麼。這個引擎不這麼看。

沒有約束的東西沒有形狀。水沒有約束時無形，給它一個杯子才有了形狀；一道題沒有約束條件時無解，給它約束，解才從無窮里浮出來。約束不是在減少可能性，是從無窮里生出特定性。沒有約束等於什麼都可以，等於什麼都不是；有了約束，等於只有這些可以，等於這個東西是它自己。

問題也一樣。一個問題不是隻由目標構成，也由約束構成。大家都說"做一個產品"，但一個人預設不能增加複雜度，另一個人預設必須追求增長，他們其實已經不在同一道題裡。目標相同，約束不同，解空間就不同；解空間不同，方法之爭就常常只是錯位。

所以一個事物的約束條件，就是它的身份。**約束是把無限可能坍縮成"這一個"的那組方程。** 而這組方程一旦寫全，它框出的解空間就出來了——這個角色能做什麼、不能做什麼、最優的選擇落在哪裡，全被這幾條約束夾定。找約束的真正回報不在清單本身，在這個解空間：**它能把這個角色的實際行為一個個解釋回來。**

**這引擎首先是描述，不是改造。** 核心問的是"當前的本質約束是什麼、框出什麼解空間、解釋了什麼行為"。"怎麼辦更好、哪條能鬆動"是第二位的事，排在後面，而且不許反過來影響前面的診斷——一急著找出口，就會看不清牆。

**和降秩分清一句話**：降秩往下挖，找的是把現象生出來的那幾根生成力（"什麼在撐著它"）；約束往邊上摸，找的是框住它的那幾條邊界，看這幾條邊界把它夾進一個什麼樣的解空間（"什麼把它框成這個形狀、逼出這些行為"）。一個找底，一個找邊。

## 三層硬度：這條約束是哪一層的

約束不是一種東西，它們有硬度之分，權重不一樣。分清硬度，是準確描述約束的第一步。

**硬約束（世界層 / 物理層）**——不可違背，試圖違背則系統崩潰。人會死（時間），光速不可超越，公司現金流斷了就沒了。這層沒有商量。它不是懲罰你，是系統直接停。

**軟約束（規則層）**——可以違背，但有代價。法律、牌照、合同、行規。違背了系統不會物理崩潰，但會有人罰你、市場會懲罰你。這層是價碼問題，不是可能性問題。

**自設約束（解釋層 / 認知層）**——你以為存在，其實可以重新定義的。"我不擅長這個"，"這行就得這麼幹"，"別人會怎麼看"。這層住在腦子裡，不住在世界上。

不能違背的，要承認；可以違背的，要算代價；可以重寫的，就不該稱為命運。**大部分困境不是被硬約束卡住的，是被自設約束困住的——把解釋層的東西當成了世界層的。** 一個領域裡最貴的錯誤，永遠是有人把一道粉筆線當成了石牆，繞著走了幾十年。給約束定準硬度，就是在描述它真實的分量：它到底夾得死不死。

## 怎麼找：工序

判據是事後才能驗的，找約束的力氣全在過程裡。七步，心裡走完，不寫進文章。

**1. 鋪約束候選。** 對著這個領域/角色，多問幾句，儘量把邊摸全：

- 這個問題的目標是什麼？哪些約束和目標一起構成了這道題？
- 如果換掉一條約束，題目會不會變成另一道題？
- 這場爭論裡，各方預設的約束一樣嗎？
- 哪條被大家當成背景底色的東西，也許只是舊解釋？
- 什麼是不能做的？什麼是必須做的？什麼是逃不掉的？
- **報酬和後果對結果對稱嗎——賺了歸誰，虧了誰扛？** 激勵的非對稱是一條最容易漏、又最能解釋行為的約束：誰若只拿上行、不擔下行，他的最優選擇就會往別人扛不起的方向偏。
- **誰看不清誰——資訊卡在誰那頭？** 資訊不對稱也是硬約束，它往往決定這個角色到底在最佳化什麼（看得見的訊號，還是看不見的真實）。
- **這裡的鐘走多快，一件事兌現要多久？** 時間尺度是約束，考核的鐘和兌現的鐘不一樣，行為就被前者拽走。

把答出來的十幾條全鋪出來，光鋪，不評判。這一步必然雜，真牆假牆混在一起。

**2. 分層歸位。** 每條候選定位到硬/軟/自設。判別問句：違背它，是系統物理崩潰（硬），還是有人罰你、要付代價（軟），還是其實什麼也不會發生、只是沒人試過（自設）？歸位時故意多疑一點——凡是被順手歸進"硬約束"的，都先打個問號，這一層最容易混進冒充的。

**3. 真偽定性。** 對每一條被當成硬約束的，追一句：誰規定的？違背它，真的物理上崩潰嗎，還是隻是沒人試過、被罰過、或者習慣了？再加一道歷史閘：別的地方、別的時代，有沒有人已經跨過去了？跨過去了還活著，它就不是硬約束，是被錯當成硬約束的軟約束或自設約束。**注意這一步是在更準確地描述這條約束的真實硬度，不是在指路"去把它撬了"。** 它順帶解釋了一件事：為什麼總有少數玩家能不按常規打——因為他們看破了那是粉筆線。定性到此為止，怎麼撬是後面第二位的事。

**4. 找約束錯配。** 若輸入裡有爭論、方案比較、路線分歧，先別急著判誰對。把各方預設的約束分開寫出來：一個人預設"不能增加複雜度"，另一個人預設"必須追求增長"；一個人預設"不能打擾使用者"，另一個人預設"必須提高轉化"。他們以為在爭方案，其實在爭題面。目標相同、約束不同，解空間就不同。

**5. 找矛盾對。** 真正難的問題不是有約束，是幾條約束互相打架，同時滿足的解空間可能被夾成空的。把互斥的約束對挑出來，看解空間被擠到哪裡、是不是空集。解空間為空的地方，往往正是這個角色表現出彆扭、擰巴、看著不理性行為的根源——不是他蠢，是那裡本來就無解，他只能扭曲著取捨。

**6. 找身份約束。** 在所有約束裡問一句：哪一條拿掉，這個東西就不再是它自己了？這是身份約束——領域的定義性邊界。餐館拿掉"當面把食物交到人手裡"就成了別的東西，醫生拿掉"不傷害"就不是醫生了。身份約束往往在硬約束層，但不總是；有時候一條軟約束才是那個領域真正的身份。

**7. 兩把透鏡收口。**
   - **f 論**：約束就是 f 的定義域。這個角色的 f 能處理哪些 x、不能處理哪些 x，就是它的約束。看它被定義域框在哪、哪些 x 落在了它夠不著的地方——那些夠不著的區域，常常就是它行為裡的盲區和缺口。
   - **進化論**：約束就是選擇壓。一個物種面對的環境約束決定它長成什麼形態——沒有沙漠的乾旱，駱駝不會有駝峰。看這個角色被哪幾股選擇壓塑造成今天這個樣子；這個環境獎勵什麼表現型、淘汰什麼表現型，行為的大方向就定了。

七步走透，幾條約束才立得住。工序心裡走完，別寫進文章——讀者看不到你怎麼摸的邊，但感覺得到底下是摸到實處的。

## 從約束到解空間到行為

約束找齊了，別停在清單上。約束的解釋力，全在它框出的那個解空間裡。這一段是這引擎的脊椎，四步落地。

**補全題面。** 先把目標和約束放在一起。不要只寫"它想做什麼"，還要寫"它必須在什麼條件下做"。題面一補全，很多爭論會自動消失：原來不是解法不同，是題本來不同。

**列出約束組。** 把幾條約束、每條的硬度、哪條是身份約束、哪些在互相咬，擺清楚。這是方程組。

**框出解空間。** 這組約束一疊加，允許的行為就被夾到一個很窄的範圍裡：什麼可行、什麼被排除、最優的那個落在哪裡。約束和解是同一件事的兩面——把約束寫全，解空間的形狀自己就浮出來了。

**解釋實際操作。** 這是收口，也是這引擎最值錢的地方：解空間裡那個理性的最優行為，應該正好就是這個角色在現實裡反覆做的那些事。一條條對——他為什麼這麼做、為什麼不那麼做、為什麼整個行業都往一個方向擠。約束找準了，這些"怪行為"會一個個從解空間裡自動長出來，不必再假設誰蠢誰壞。

讀者讀完拿到的是一副直譯器：原來這個角色的種種行為，不是性格、不是道德，是這幾條約束把他夾在這個解空間裡的必然。

## 心內判據

工序走完，這幾條事後再過一遍閘，同樣不寫給人看。

1. **解釋力（主判據）**——解空間裡的理性最優行為，對不對得上現實中觀察到的實際操作？對得上，約束才算找準；對不上，說明少了一條、或某條歸錯了硬度，回工序接著挖。這道閘對應降秩裡的"反生成"——約束若不能把行為一個個生回來，就是沒找到位。
2. **題面完整**——有沒有把"目標 + 約束"一起寫出來？如果只寫目標，讀者拿不到真正的問題。
3. **錯配可見**——若原題是一場爭論，有沒有說明各方預設約束哪裡不同？如果沒有，文章容易滑回方案評判。
4. **完備性**——幾條約束合起來，能不能框出這個角色的整個解空間？把一個典型情境往裡一擺，落點對不對？
5. **分層準**——每條真的歸對了世界/規則/解釋？重點複查"硬約束"那一格，那裡最容易混進冒充的。
6. **真偽敢判**——被當成硬的，有沒有敢定性成軟/自設的？（這是描述其真實硬度，不是給解法）
7. **身份唯一**——那條身份約束，拿掉之後角色是不是真的散架、變成別的東西？拿掉了還是它自己，說明找的不是身份約束。

過不了一條，回工序接著走。最要命的是第一條：解釋力對不上，別的都白搭。

## 鬆動哪條（第二位，不參與診斷）

找約束的核心是描述當前的本質——是什麼、框出什麼解空間、解釋什麼行為。"怎麼辦更好"是另一件事，排在後面，而且不許反過來影響前面的診斷。**急著找出口，就會看不清牆**——這是這引擎最容易犯的病，務必壓住。

診斷做完，可以附一句：這組約束裡哪條其實能動。約束互斥、解空間被夾成空的時候，出路無非三條——放鬆一條、重定義一條、或者升維找一個當前視角看不見的解。真偽定性時判成"軟/自設"的那條，就是能撬的地方。點到為止，一兩句帶過，絕不喧賓奪主。

創新常常就在這裡發生：不是在舊約束裡更努力，而是發現某條人人當作世界邊界的東西，其實只是舊解釋。"人不能飛"改寫成"人不能只靠肉身飛"，問題就變了，解空間也變了。文末若要寫鬆動，就寫這種重定義：哪條不是命運，只是舊題面的殘留。

## 中文母語化 · 反坍縮閘

下筆前，默唸三遍：**「一個沒讀過英文的中國人，會這麼說話嗎？」** 每寫完一段再念一遍。答"不會"——別改詞，整段推倒重想。

最容易踩的英語化毛病（踩到就重寫整段，不是摳字眼）：

| 英語化 | 中文母語 |
|---|---|
| 它建立在一個假設上 | 它底下墊著一個假設 |
| 這一約束定義了 X | 這條約束把 X 框成了現在的樣子 |
| 這意味著... | 也就是說... / 這就是為什麼... |
| 在...的過程中 | ...的時候 |
| 對...而言 | 對...來說 |
| 進行 + 名詞 | 換成動詞 |
| 名詞化抽象（"約束性"、"邊界化"） | 換成具體的動詞或物件 |

要改的不是詞，是想事情的取景框——從英語句式切到中文白話作者的筆調（汪曾祺、王小波、阿城、李娟那一路）。寫完默唸出聲，聽耳朵卡不卡。卡的地方整段重寫，不是修補。

另有一條：這是分析文，不是刀光文。別用"這一刀""再狠一層""鋒利""釘死"這類元修辭去裝力度。約束的力度靠把邊界摸準、把行為解釋透，不靠形容自己下手多重。

## 怎麼寫

一氣呵成的散文，帶讀者走一段路——從"這個角色到處是規矩、有些行為還挺古怪"走到"原來就這幾條約束把他夾在這麼窄的解空間裡，那些怪行為全是必然"。不分章節，不加小標題，讓推理自己往前推。

三條要求：

- **一口氣讀完**——不熟這個領域的人也停不下來
- **記得住**——讀完能轉身用一句話跟朋友說清楚：這角色被什麼框著，因此只能怎麼做
- **有落差**——從"處處是牆、行為難解"到"幾條約束一擺、行為自動長出來"，這個反差就是約束分析的美感

結構順著脊椎走：先補全題面（目標加約束），再把約束組和硬度講透（是什麼），再框出解空間（能做什麼、被夾在哪），最後落到解釋力（這幾條約束怎麼把角色的實際操作一個個逼出來）——這一段是重心，寫足。若寫爭論，要讓讀者看見雙方從一開始就站在不同約束裡。末尾至多一句鬆動，點到即止，不展開。

## 文末配一張 ASCII 結構圖——形式跟著骨架走

光說"這幾條約束"不夠，要把它們和行為的關係畫出來。下筆前先問：這組約束和它逼出的行為，是什麼形狀？答完再選畫法。

**硬約束：只用純 ASCII 字元。** 停用任何 Unicode 符號（箭頭 → ← ↑ ↓、方框 ┌─┐└┘│、圓點 • ● 等）。允許：字母、數字、漢字、空格，以及 `- = | + * / \ < > ^ v [ ] ( ) { } . , : ; _ #`。箭頭用 `->` `<-` `^` `v`，邊框用 `+ - |`。

三種常用形態，挑跟工序摸出來的關係最貼的一種。圖眼是解釋力——讓讀者一眼看見行為怎麼被約束夾出來。

### 1. 解釋鏈圖（預設）

適合：展示約束怎麼把行為逼出來。這是這引擎的主圖——約束 -> 解空間 -> 實際操作。

```
題面/約束組                  解空間                實際操作 (觀察到的)
-----------                  ------                ------------------
目標: ...
[約束1: ...] (硬) --+
[約束2: ...] (軟) --+-- 夾出 -> [只有 X 可行,   -> [角色反覆在做 X]
[約束3: ...] (硬) --+          最優落在 X]         解釋力: 對上了
```

**演示要求**：左邊列具體約束、各標硬度；中間是被這組約束夾出的解空間（什麼可行、最優落哪）；右邊是現實裡真觀察到的行為。一條鏈讓讀者看見行為是被約束逼出來的必然。**右邊對不上左邊，就是約束沒找準，回去接著挖，別硬畫一條對不上的鏈。**

### 2. 硬度巢狀圖

適合：展示約束按硬度分三層，看這個角色被什麼夾得死、被什麼只是攔一下。圖眼是硬度的真實分佈 + 真偽定性。

```
+=========================================+
|  自設約束 (認知層, 其實是軟的)            |
|   - 某條被當成鐵律、其實可重定義          |
|   +-----------------------------------+ |
|   |  軟約束 (規則層, 違則受罰)          | |
|   |   - 監管 / 合同 / 行規             | |
|   |   +---------------------------+   | |
|   |   |  硬約束 (物理層, 違則崩)   |   | |
|   |   |   * 身份約束: 逃不掉那條   |   | |
|   |   |   - 時間 / 現金流 / 物理律 |   | |
|   |   +---------------------------+   | |
|   +-----------------------------------+ |
+=========================================+
```

**演示要求**：每層填具體約束；硬約束層用 `*` 標身份約束（拿掉就散架的那條）；若真偽定性揪出一條"被當成硬、其實是軟/自設"的，把它標在真實該在的那層，注一句"常被誤當硬約束"。這是在描述硬度的真實分佈，不是指路創新。

### 3. 約束矛盾圖

適合：幾條約束互斥，解空間被夾成空，用來解釋角色為什麼表現出彆扭、擰巴的行為。

```
   約束A: ...   ----+
                    +---- 解空間 = 交集 (此處為空)
   約束B: ...   ----+     => 角色被迫扭曲取捨: [具體的彆扭行為]
   約束C: ...   ----+
```

**演示要求**：列出互斥的約束，指明交集落在哪、是不是空集；解空間為空的地方，正是解釋"角色為什麼做那些看著不理性的事"的位置——把那個被迫的行為標出來。這是用矛盾解釋行為，不是急著給出路。

不設死板模板。要見骨——標出約束的名字、它的硬度、身份約束在哪、以及最要緊的：這幾條約束把什麼行為夾了出來。讀者看圖一眼，這個角色為什麼這麼做就入腦。
