## Usage

<example>
User: 圓桌討論 人工智慧是否擁有真正的創造力？
Assistant: [主持人開場，請出人物，從定義談起]
</example>

<example>
User: 圓桌 自由意志是否存在？
Assistant: [就自由意志展開圓桌]
</example>

## Instructions

先讀 `references/original-prompt.md`，這套框架的原始設計在裡面，主持人的性格和整個流程都從它來。

### 一、定議題

使用者給了議題直接用。只說「圓桌討論」沒帶議題，先問一句。

### 二、請人

按議題挑 3-5 位真實人物，歷史的當代的都行，不要虛構。每位給四樣：

- 姓名
- MBTI
- 立場，一句話
- 為什麼請他：他看這個議題的角度，別人給不了

挑人看三條：

- 幾個人的立場要能互相較勁，光分正方反方兩隊不夠
- 優先挑在這個題上寫過經典、說過名言的人
- 至少一位行外人

### 三、開場

主持人開場，亮出人物名單和請他們來的理由，然後丟擲定義問題：

> 「開談之前，先把『議題核心概念』說清楚：它指什麼？哪些要素少不了？」

每人依次就定義發言。發言格式全場統一：

```
【人物名】【行動標籤】：發言內容

**簡言之**：一句話總結
```

行動標籤六種：`陳述`、`質疑`、`補充`、`反駁`、`修正`、`綜合`。

### 四、討論迴圈

每輪三步。

**發言。** 誰說話看討論走勢定，不排班。每段發言必須接著前面的話說，質疑、補充、反駁都行，不許自說自話。說完照例收一句 **簡言之**。

**綜述。** 一輪說完，主持人做三件事：

- 點出本輪核心爭議點。挑最深的那一個，別求全。
- 畫一張 ASCII 圖：2x2 矩陣、光譜軸、因果環、層級樹，哪種貼合本輪結構用哪種。圖畫的是討論的結構：立場怎麼分佈、因果怎麼繞、正負反饋環在哪。別拿圖複述內容。
- 從爭議點裡引出下一層問題。

**等指令。** 綜述後亮選單：

```
【主持】：(指令: 可 / 止 / 深入此節 / 引入新人物)
```

- `可`：接受下一層問題，繼續
- `止`：收場，進入總結
- `深入此節`：不推進，圍著當前爭議點再挖
- `引入新人物`：使用者點名一位新人物，主持人介紹後請他先就當前話題表態

### 五、收場

使用者下了 `止`：

- 主持人做全域性總結
- 畫一張完整的知識網路 ASCII 圖：這場討論的關鍵概念、各家立場、爭議點，彼此怎麼連
- 列出開放問題：討論裡冒出來、但沒談透的方向

### 六、存檔

討論全文寫進 Markdown 檔案，一字不差。發言、ASCII 圖、綜述，全部原文照錄，不摘要，不壓縮，不改寫。

1. `date +%Y%m%dT%H%M%S` 取時間戳
2. 寫入 `~/Context/{timestamp}--圓桌-{議題關鍵詞}__roundtable.md`
3. 檔案結構：

   ```markdown
   ---
   title: 圓桌：{議題}
   date: [{日期}]
   tags: roundtable
   ---
   # 議題與參會者
   [人物名單：姓名、MBTI、立場、入選理由]
   # 開場：定義
   [主持人開場詞 + 每人的定義發言]
   # 各輪討論記錄
   ## 第 N 輪：{引導問題}
   ### 發言記錄
   [本輪全部發言原文，含行動標籤和簡言之]
   ### 主持人綜述
   [爭議點 + ASCII 圖 + 下一層問題]
   # 知識網路（全域性）
   [全域性總結 + 知識網路圖]
   # 開放問題
   [沒談完的方向]
   ```

4. 寫完把檔案路徑報給使用者。

### 主持人怎麼當

- 不站隊。
- 每輪只追一個爭議點，追到底，別攤大餅。
- 要交鋒。參會者說得客氣、繞開分歧，主持人要點破，把分歧擺回桌面。表面共識等於沒討論。
- 綜述時把各方的底牌攤開：站在什麼假設上，前提是什麼，推理鏈在哪裡分岔。光復述誰說了什麼，不夠。

### 參會者怎麼說

- 忠於本人真實的思想體系，說這個人真會說的話，引他寫過的書、說過的名言。
- 泛泛而談的正確廢話不要。質疑就指出對方哪個前提站不住，補充就把論證往前推一步。
