# ljg-classic：古文箋

原文是主幹，註解貼著字詞生長，章節解讀把整章重新接成一個能執行的判斷。最終交付一張標明書名與章節的 PNG 長圖到 `$HOME/Downloads/`；生成與複驗過程留在獨佔 `/tmp` 工作區。

## Workflow Notification

執行工作流時，只輸出文字通知：

```text
Running the **AnnotateAndRender** workflow in the **ljg-classic** skill to annotate and render the chapter...
```

不傳送開始、階段或進度語音；完成語音由系統統一處理。

## Workflow Routing

| Workflow | Trigger | File |
|---|---|---|
| **AnnotateAndRender** | 逐字註解、彩色夾註、章節解讀、生成古文 PNG | `Workflows/AnnotateAndRender.md` |

## 快速合同

- 輸入必須能確定原文、書名、章節；版本不明時保留異文邊界。
- 所有非標點原文片段都有對應註解，不能只挑“重點詞”。
- 青色解釋字詞與語法，硃色解釋整句動作，赭色只標異文與不確定處；章節解讀使用暖紙深墨，不用藍色長正文。
- 解讀借用 `ljg-explain` 的直白中文與理解標準和 `ljg-writes` 的「條件—機制—結果、遷移、邊界」，產物仍遵守本工作流，不額外附加自測或寫作腳手架。
- 預設呼叫內建 `image_gen` 生成一幅無字、低干擾的章節意旨圖，放在章節標題與原文之間；影像不可用時繼續生成無圖版本並說明。
- 每次執行先建立獨佔 `/tmp/ljg-classic-*` 工作區；JSON、HTML、manifest、意旨圖、候選 PNG 與重疊 QA 切片都只放在該工作區。
- 候選 PNG 完成硬驗收後，才複製到 `$HOME/Downloads/` 作為最終卡片；使用者顯式指定另一最終路徑時以本次指令為準。未經明確要求不覆蓋同名檔案。

## Gotchas

- “逐字”指原文覆蓋率 100%，不等於把固定詞拆成失去意義的單字；成詞、虛詞功能和通假關係按最小有意義單位注。
- 註解不能改寫原文。底本疑似錯字、通假或版本差異用 `variant` 標出，不能靜默替換。
- 字詞注與句義注若都寫成長句，原文會被淹沒。字詞注只解決區域性讀法，句義注只補當前動作或因果。
- 章節解讀不是逐句譯文的重複，也不是金句合集。它只執行一個主關係，並說明一個可遷移場景或失效邊界。
- 邊界要自然寫進文章，不另起「解讀邊界」「應用邊界」「遷移測試」之類的方法標題；這些詞會讓讀者從內容中跳回寫作後臺。
- 頂部配圖負責壓縮母題，不負責複述情節。禁止圖中文字、書法、印章、水印與高飽和宗教奇觀；畫面細節太滿會搶走原文的第一閱讀權。
- PNG 檔案存在不算完成。必須核對真實尺寸、標題章節、註解覆蓋、頁面底部、整圖與長圖切片。
- 不直接渲染到 Downloads。先在 `/tmp` 驗收候選 PNG，再複製最終卡片，並讀回候選與交付檔案的 SHA-256 一致性。
- 影像寬度固定不代表字號固定。文字量增加時先增高頁面和調整斷行，不能把正文字號壓到難讀。
- 標點不能作為可獨立換行的單元。句末標點與閉引號跟住前一原文 token；段首引號跟住後一 token，避免孤行。

## Examples

**Example 1：整章古文排版**

```text
User: 「/ljg-classic 《道德經》第十六章，逐字註解並講透」
→ 鎖定書名、章節與底本
→ 逐段生成字詞注、句義注和全章解讀
→ 在獨佔 `/tmp` 工作區完成驗收，只把帶書名章節的 1080px 長 PNG 交付到 `$HOME/Downloads/`
```

**Example 2：使用者提供原文**

```text
User: 「把這段《論語·學而》做成文言文夾註圖，最後寫完整解讀」
→ 原文逐片段覆蓋，通假與語法另行標色
→ 解讀用直白中文跑通條件、機制和結果
→ JSON、HTML、manifest、配圖和 QA 切片保留在 `/tmp`；最終 PNG 交付到 `$HOME/Downloads/`
```

**Example 3：只翻譯一句**

```text
User: 「這句古文是什麼意思？」
→ 不觸發 ljg-classic
→ 直接做簡短翻譯；需要講透章內概念或原理時使用 ljg-explain
```
