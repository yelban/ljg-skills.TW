# Layout Grammar

## 視覺判斷

頁面只做一件事：讓眼睛先沿黑色原文讀，再在遇到阻力時看身邊的彩色注，讀完整章後自然落到藍色解讀。

## 頁面骨架

```text
書名
章節

章節意旨圖（可選；橫向、無字、低干擾）

原文 + 青色字詞注 + 硃色句義注 + 赭色異文注
原文 + 彩色夾註
...

章節解讀
藍色自然段
藍色自然段

來源
```

- 畫布：`1080 × auto`，暖白或純白底。
- 左右安全區：72–92px；頂部 72–96px；底部 64–88px。
- 書名與章節居中，正文左對齊。
- 一張圖承載完整章節；高度隨內容增加，不壓縮成海報。

## 字型層級

| 層 | 建議字號 | 字型 | 顏色 |
|---|---:|---|---|
| 書名 | 54–68px | `Songti SC` / `STSong` | 墨黑 |
| 章節 | 48–62px | `Songti SC` / `STSong` | 墨黑 |
| 原文 | 42–52px | `Songti SC` / `STSong` | `#171512` |
| 拼音 | 18–22px | 系統無襯線 | `#52615e` |
| 字詞注 | 22–28px | 系統無襯線 | `#27988a` |
| 句義注 | 22–28px | 系統無襯線 | `#d84a42` |
| 異文注 | 22–28px | 系統無襯線 | `#b7790b` |
| 章節解讀標題 | 28–32px | 系統無襯線 | `#795f43` |
| 章節解讀正文 | 26–30px | `Songti SC` / `STSong` | `#39342e` |
| 來源 | 18–22px | 系統無襯線 | `#77716a` |

原文行高 1.8–2.05；章節解讀行高 1.75–1.95。字號寧可穩，不用誇張標題擠壓正文。

## 夾註關係

- 原文 token 與其註解組成不可拆單元；允許單元之間換行，不允許括號與註解正文分家。
- 逗號、句號、問號、歎號和閉引號跟隨前一原文 token；段首引號跟隨後一 token，不能單獨換行。
- 彩注比原文小約 45%，貼近原文基線或略抬高，不能像腳註一樣遠離物件。
- 拼音只浮在對應原文上方。
- 原文可用細點線提示被注位置，但下劃線不應比文字更搶眼。
- 同一註解只用一種語義色。藍色不進入夾註區。

## 章節解讀區

- 用 52–72px 留白與原文分開，再鋪一層極淺暖灰褐底（建議 `#eee8dc` 附近）；不使用純白底上的彩色長正文。
- 正文使用接近墨色的暖黑（建議 `#39342e`），標題只用低飽和茶褐色；藍色不進入章節解讀區。
- 解讀區可有細邊線，但不用圓角卡片、投影或懸浮效果。它應像同一張紙的另一層墨，而不是嵌入的網頁元件。
- 標題只寫「章節解讀」，不新增營銷副標題。
- 第一段略深、略大且不縮排，承擔全章判斷；後續自然段首行縮排兩字，行高 1.9–2.0，段距小於原文區的模組間距。
- 遷移與邊界自然寫進文章，不另加「解讀邊界」「應用」「遷移」「侷限」等方法標籤。

## 頂部意旨圖

- 位置固定在章節標題與原文之間；先定氣息，再進入文字。
- 推薦橫向 3:2，寬度佔正文安全區 100%，畫面自身保留安全邊緣；不得讓瀏覽器隨意裁掉主體。
- 使用暖象牙、菸灰、茶褐和極少硃砂；低飽和、低對比、大留白。影像濾鏡只能輕微降飽和與對比，不能把失真的圖救成合格圖。
- 圖內不得出現任何文字、書法、標題、印章、水印或裝飾邊框。
- 主體要小，母題要清楚。配圖的視覺重量低於章節標題和第一行原文，不能把長圖變成插畫海報。
- 底部用極淺漸隱或留白接回紙面，避免硬切成另一張圖。

## 禁止項

- 米黃色仿古紋理、卷軸邊框、印章、祥雲等裝飾不得擠佔閱讀面積。
- 除頂部配圖接回紙面的極淺漸隱外，不用裝飾性漸變、陰影、玻璃卡片、熒光筆大色塊。
- 不把長注塞進原文中間造成“彩色正文”。
- 不讓書名、章節、來源缺席。
- 不靠瀏覽器視口高度裁圖；必須按完整文件高度截圖。

## 視覺驗收

整圖回答層級，中段回答可讀性，底部回答完整性。長圖必須看覆蓋全高的重疊切片；只看縮略整圖會漏掉區域性遮擋、斷行和裁切。
