# Annotation Method

## 一條原則

註解負責把原文中的區域性阻力拿掉；章節解讀負責說明整章為什麼這樣安排。兩層不能互相代替。

## 切分單位

按最小有意義單位切，不機械逐字拆：

- 固定詞、成語、官名、地名保留為一個 token。
- 古今義變化明顯的單字可獨立成 token。
- `之、其、以、而、於、者、也` 等虛詞按本句功能注，不能複製同一釋義。
- 通假字以原字留在 `text`，在 `note` 說明所通之字；不能先改原文再注。
- 標點單獨作為 `{ "text": "，", "punctuation": true }`，不寫偽註解。

“逐字註解”通過覆蓋率兌現：所有非標點 token 都有 note。切分的目標是讓每一注都能落到一個明確語言動作上。

## 三類夾註

| tone | 顏色語義 | 回答的問題 | 典型內容 |
|---|---|---|---|
| `word` | 青色 | 這個字詞在此處是什麼意思 | 古今義、虛詞功能、語法、讀音 |
| `clause` | 硃色 | 這一小句在做什麼 | 誰對誰做什麼、動作結果、區域性因果 |
| `variant` | 赭色 | 這裡為什麼不能裝作只有一種讀法 | 通假、異文、版本差異、解釋分歧 |

每條 note 優先 2–14 個漢字。超過 22 個字，通常已經越過區域性註解邊界，應改寫或移入章節解讀。

## 拼音

只給會改變理解的生僻讀音、多音字和古音提示。格式不帶聲調數字時用帶調拼音；無法確認時不猜，改用 `variant` 說明。

## 章節解讀

章節解讀只保留一個主關係。它至少讓人看見：

1. 章內哪些詞是同一臺機器的不同零件。
2. 條件怎樣觸發動作，動作怎樣產生結果。
3. 為什麼只按現代常識直譯會漏掉關鍵一步。
4. 這條關係還能遷移到哪裡，或在什麼條件下失效。

先直白，再準確；術語只在大白話已經落地後出現。不要把逐句譯文重新拼成一段，也不要用“人生智慧、值得深思、發人深省”填空。

## 事實邊界

- 原文事實來自底本；解釋是解釋，不能偽裝成作者自述。
- 章旨存在學術分歧時，寫清“本圖採用哪一種讀法”。
- 現代案例只檢驗結構，不證明古人原意。
