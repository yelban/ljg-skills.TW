# ljg-read · 伴讀

把一段文本講到讀者能看見它說的事情、認出其中的概念、跟上關鍵推理，並知道換個情境還能不能成立。預設完整講解當前所給文本，直接在對話中展示。

## Workflow Routing

| 請求 | 執行 |
|---|---|
| 貼上文本、提供檔案或 URL，希望講透 | 按「下上結構」與「講解約定」交付 |
| 「快進」「展開」「等一下」或希望提問伴讀 | 按「可選互動」調整當前講解 |
| 明確要求儲存 | 按使用者指定位置與格式儲存；未要求時只在對話中展示 |

## 《學習觀》的下上結構

依據於建國《學習觀：從感覺懂了到真正學會》關於「下上結構」、判別模型、聯結模型與學習驗證的論述。以下是用於伴讀的轉述；講解安排是本技能的應用設計。

**下層是實際問題，上層是理解問題的工具。** 下層放這次要理解的具體物件、情境及其變化；上層放相關概念與概念之間的通用關係。作者將「下」放在前面，強調實際問題優先。兩層是相對的：這次作為工具的概念，換個問題也可以成為研究物件，不能把「下」固定成物質、「上」固定成語言。

**判別模型接通物件與概念。** 它回答「眼前這個情況，憑什麼算這一類？」講一個概念時，要讓讀者看見所指、歸類依據，以及容易混淆的邊界。定義或名稱本身不足以證明讀者能在新情境認出它。

**聯結模型接通概念之間的關係。** 它回答「知道了這一類情況，在什麼條件下能推出什麼？」歸類正確與關係成立要分別說明；會背規律不保證會識別適用場景，認出類別也不自動證明規律。

**材料和驗證承擔不同作用。** 具體例子幫助建構，抽象表述幫助整理，未見情況用來檢驗遷移。複述已講例子不足以證明會遷移；給出新情境、請讀者判斷並觀察回答，才可能發現理解斷在哪裡。沒有讀者反饋時，只能說講解提供了遷移檢查，不能聲稱讀者已學會。

## 講解約定

### 原文與範圍

- 先讀到實際內容。貼上文本直接使用；檔案讀取指定內容；URL 用當前可用的網頁獲取能力。拿不到正文時說明缺口，不根據標題或摘要補寫全文。
- 圍繞使用者給定範圍講解。短段可直接深入；長文按完整語義單元組織，保留主線、重要分支與轉折，不逐句平均用力，不切斷承重論證。
- 中文直接解釋。英文先給自然、準確的中文譯文，保留影響判斷的英文短句或術語作為校驗錨點；僅在語言歧義、行話或文化典故影響理解時補充說明，不固定疊加三套翻譯。

### 把下層與上層接通

先用一句普通話點明作者在回答什麼問題、作出什麼判斷。隨後圍繞承重處展開，通常從一個能看見細節的情境進入，再提煉概念與關係，最後回到具體情境說明所得判斷。安排隨文本而變；以下是講清楚的要求，不是必須逐項列印的欄目。

- **讓事情可見。** 優先使用原文例子；原文太抽象時補一個貼近日常的教學設例，並就地標明。例子有具體的人或物件、條件、變化與結果；「好人也會死」這類只給抽象詞加限定的句子，不能替代真正的下層材料。
- **讓概念可辨。** 用普通話說明關鍵概念是什麼、與相鄰概念差在哪裡。結合例子指出哪些事實使它屬於這一類；容易誤認時給一個只差關鍵條件的近鄰情境。僅有描述或比喻時，保留其模糊處，不替作者發明精確標準。
- **讓關係可追。** 把作者從前提走到結論的關鍵一步展開，說明中間發生了什麼、依靠哪些條件。區分定義、分類、相關、因果、類比、價值判斷和行動主張；箭頭或公式按實際關係使用，不把所有文字改造成因果定律。
- **讓兩層對得上。** 明說例子裡的什麼對應哪個概念，憑什麼對應；若有預測，再說明如何使用關係、所得結果在例子裡意味著什麼。不能從生活故事直接跳到大道理，也不能把抽象結論換個說法就當作講解。
- **讓邊界改變判斷。** 選能觸及承重前提的條件變化、反例或未決處，說明它使歸類變化、關係失效，還是隻收窄結論。原文沒有足夠依據時留下未知，不為了完整替作者補成已證實的機制。
- **讓遷移可檢查。** 適合遷移的內容可收一個與已講例子不同的小情境，讓讀者判斷「是否適用、依據是什麼、能推出什麼」。預設可附簡短參考分析；若使用者選擇互動自測，先只給題，等其回答再反饋。答案揭曉後，該題就屬於講解材料。

論證文本重在概念、依據與推理；敘事或抒情文本重在具體處境、人物變化、意象與表達效果。解釋人物動機時區分原文所示與推測，詩意和多義性可以保留，不強求預測公式或唯一答案。

### 對話成品

預設中文 Markdown，以連貫段落講解。短文本不硬分章；長文本用貼合內容的小標題。並列比較才用表格，承重關係確實難以看清時才加簡短文本圖或公式；符號先解釋，再使用。

正文應讓讀者看見原文的主要意思、概念與情境的對應、推理的成立條件，以及一個足以改變判斷的邊界。結尾用一句話收住最值得帶走的理解；不例行堆術語表、延伸書單或強制讀後提問。

原文陳述、解釋者的推論、補充教學設例分清。引用限於講解所需，避免大段復刻受版權保護的來源。補充理論、事實或外部引文需有可核對來源；類比說明對應和失配處，不冒充證據。

**伴讀結果預設只展示在對話中。** 不自動建立或更新筆記、Org 檔案、對話記錄、學習檔案、記憶或其他產物，不返回虛構的檔案路徑。原文保持只讀；使用者另行明確要求儲存或修改時，以其指定範圍為準。

## 可選互動

- **預設**：連貫講完當前範圍，提問不作為繼續講解或完成交付的門檻。不推測讀者已理解，不強制讀者表態。
- **快進**：壓縮鋪陳與次要解釋，保留主判斷、關鍵對應與適用條件。
- **展開**：針對卡住的位置補具體例子、概念辨析、推理步驟或邊界，不重新重複整篇。
- **等一下**：停在當前位置，處理讀者指出的疑問。
- **提問伴讀／互動自測**：一次只圍繞一個真實缺口提問，等回應再推進。答錯時定位歸類、關係或條件哪處斷開，用針對性材料修正，不以「說服了沒有」替代理解檢查。

## Gotchas

- 「下上結構」用於檢查具體與抽象是否接通；它不要求每段都列印「下層／上層」或畫成固定三層圖。
- 多個例子若只換姓名或數字，可能仍在重複同一個表面形式。需要時改變情境或關鍵條件，檢查讀者是否掌握歸類依據。
- 原文的結論強弱和證據範圍應保留。一個教學例子、一次正確回答或模型間的一致，均不足以證明普遍規律或讀者已經掌握。
- 通俗表達保留承重區別。類比不能替代定義，故事不能替代機制，反例不能靠偷偷改題製造。
- 聽懂、認同、記住與會用分別判斷；沒有回答或實際應用證據時，不評定學習成敗。

## Examples

- `/ljg-read 「激勵會改變人的行為。」`：用有條件的教學設例講清「激勵」「行為變化」的對應，解釋作者主張的關係；區分行為增加與目標改善，並指出原句尚未限定的條件。
- `陪我讀這段英文，直接講透`：給自然中文譯文，在關鍵原句處核對；用具體情境、概念辨析與承重推理完成解釋，直接在對話中交付。
- `這段我感覺懂了，換個例子考考我`：給未講過的情境，先不揭答案；根據讀者實際回答定位歸類、關係或條件的缺口，不建立學習記錄。

## 交付檢查

讀回解釋與原文：主要意思和重要分支是否保留，關鍵概念能否在具體情境中辨認，關係的依據與條件是否清楚，補充例子是否標明，邊界是否真的會改變判斷。檢查只證明當前講解覆蓋了這些要素；讀者是否學會，仍需其反饋。
