# ljg-invest: 投資報告

給一個專案，寫一份投資分析。整份報告只回答一個問題：這個東西在創造新秩序，還是在搬運舊秩序。

## 地基

一個定義撐著整份報告：財富不是錢，是被慾望照亮的秩序，錢只是秩序的計量單位。投資，是拿手裡的秩序，去換一臺更好的秩序生成器。

從這個定義出發，報告的問法和市場慣例不一樣：

| 慣常問法 | 這份報告問 |
|----------|------------|
| 這個公司值多少錢 | 這臺機器轉不轉得起來 |
| 市場有多大 | 市場在用什麼過時的標籤看它 |
| 能漲多少 | 我拿什麼換什麼，換完之後誰更聰明 |

## 輸入

公司名、BP、文字介紹、對話記錄，任何描述專案的材料都行。知名公司只給名字就夠——用 Research skill 或 subagent 抓最新財報和行業資料，別憑舊印象寫。

## 報告結構

五個區塊是骨架，不是填空題。哪個區塊對這個專案最有料，哪個就多寫；沒料的一兩句帶過，或者乾脆跳過。報告為判斷服務，湊完整沒有意義。

### 一、這是什麼

一張表，加一句自己下的賽道定義。

| 維度     | 內容                                         |
|----------|----------------------------------------------|
| 專案名稱 |                                              |
| 賽道定義 | 用我們自己的話說，不抄市場標籤               |
| 階段     |                                              |
| 融資情況 | 金額 / 估值 / 條款（有則填，無則標註）       |
| 資料快照 | 關鍵運營資料                                 |

賽道定義要說出這家公司真正在做什麼——市場標籤說不出的那一層。叫它「搜尋引擎公司」等於什麼都沒說；說它是「人類認知基礎設施的壟斷運營商」，它靠什麼賺錢、怕什麼，全在這一句裡。

### 二、秩序創造機器判定

整份報告的分量都壓在這一節。不逐項打分，回答一個問題就夠：**這臺機器轉不轉得起來？** 從三個角度看。

**飛輪在不在轉？**
先找系統裡那個越用越好的迴圈：使用者多了資料多，資料多了產品好，產品好了使用者更多。找到了，看它走到哪一步——停著、剛起步、已經轉起來；轉著的，再看轉了多久、是在加速還是走平；停著的，寫出卡住它的那一環。

**衝擊後變強還是變弱？**
競爭殺進來、技術換代、市場塌方，這臺機器會碎掉、扛住，還是把衝擊吃成自己的燃料。翻它的歷史：捱過打沒有，捱打之後是弱了還是壯了。

**資源是被推過來的，還是自己來的？**
擴張靠一個一個談、一塊一塊買，那是推；別人主動湧過來、不來就吃虧，那是引力。找「不推而聚」的跡象。

**綜合判定**，三檔取一：

- 秩序創造機器——飛輪在轉，衝擊後變強，資源自己來
- 有潛力——飛輪的結構在，還沒驗證轉得起來
- 秩序搬運——把已有的東西重新排列，沒有生出新秩序

### 三、創生公式

每臺秩序創造機器都有一個核心演算法，用一句話寫出來。參考：

- 亞馬遜 = 利潤→再投資→降成本→降價→更多使用者→更多利潤
- 特斯拉 = 硬體採資料→資料訓練演算法→演算法重新定義硬體
- Google = 每次人類找答案的方式遷移時，成為新方式的預設基礎設施

寫完追兩問：這個公式驗證過幾次、驗證到什麼程度；有沒有別人在跑相似的公式，差在哪。

### 四、市場看見的 vs 我們看見的

投資時機在這一節裡定。

**它在 S 曲線的哪裡？**
積累期、拐點、加速期、平臺期，落在哪一段。落在拐點之前的，寫清什麼條件會觸發拐點。

**市場在用什麼舊眼睛看它？**
市場給它貼了什麼標籤，這個標籤遮住了什麼，我們的框架多看到了什麼。這個認知差有多大——超額收益從這裡來。認知折價，看三個訊號：得費很大勁解釋別人才聽得懂；定價長期反常，部分加起來不等於整體；現成的類比全對不上，像 X 又不像 X。

**它控制了什麼別人拿不走的東西？**
它攥著的是資料、分發、標準，還是網路效應。這種控制是靜態的（品牌、專利），還是越變越強的。再往前看一步：這種稀缺以後會不會挪窩，專案跟不跟得上。

**它在搭哪趟便車？**
三種成本正在坍縮：理解成本、協作成本、行動成本。這個專案騎在哪一種上，坍縮放出來的能量它接住了多少。

### 五、換不換

- **交換建議**：建議投資 / 建議觀察 / 建議放棄
- **如果投資**：建議金額範圍、關鍵條款
- **核心假設**：這個決策押在哪幾個假設上。每個假設配一個退出訊號——什麼資料出現，說明假設錯了，該走了。
- **未解問題**：3-5 個對決策要緊但還沒有答案的問題，按輕重排。

### 最後一句

一句話回答：這個專案的本質是什麼——創造新秩序，還是搬運舊秩序。

## 生成規則

1. 只用真實資訊。查不到的直接標註，不硬撐，不編。
2. 敢下判斷。「既可能好也可能壞」這種話一句不許有。
3. 每個判斷帶證據：資料、引用、具體事實。
4. 這些詞停用：賽道很大、團隊優秀、前景廣闊、藍海市場。
5. 篇幅以說透為準。兩千字說得清就兩千字，要七千字就七千字。
6. 中文撰寫。
