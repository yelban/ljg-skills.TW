# 商業模式畫布：分類與空間合同

依據 Alexander Osterwalder、Yves Pigneur 的《商業模式新生代》（Business Model Generation）及 Strategyzer 官方 Business Model Canvas。以下為要點歸納與中文改編，未聲稱逐頁複核整本書。

## 九個模組

| JSON 鍵 | 模組 | 這格回答什麼 | 與鄰格的邊界 |
|---|---|---|---|
| customer_segments | 客戶細分 | 為哪類人／組織創造價值？誰使用，誰付款？ | 避免「所有人」；平臺兩邊分別寫 |
| value_propositions | 價值主張 | 客戶在哪個場景得到什麼結果，為什麼選擇它？ | 產品功能要接到客戶收益；不要只寫口號 |
| channels | 渠道通路 | 客戶怎樣發現、評估、購買、獲得交付與售後？ | 按路徑寫，避免只羅列社交平臺 |
| customer_relationships | 客戶關係 | 怎樣建立、維持、深化與客戶的關係？ | 人工服務、自助、社群、共同創造等互動機制 |
| revenue_streams | 收入來源 | 誰為什麼價值付款，按什麼單位／週期收費？ | 融資不是收入；標清一次性與持續收費 |
| key_resources | 核心資源 | 實現價值必須具備哪些資產或能力？ | 場地、裝置、品牌、資料、人才、資金等存量 |
| key_activities | 關鍵業務 | 為實現價值必須持續做哪些事？ | 描述動作；別把資產名重複放進來 |
| key_partners | 重要合作 | 依賴哪些外部夥伴，分別提供什麼？ | 普通客戶不自動成為夥伴；採購關係按必要性取捨 |
| cost_structure | 成本結構 | 哪些活動／資源消耗成本，主要由什麼驅動？ | 固定與變動支出；金額與週期保持來源口徑 |

客戶細分決定價值主張的物件；渠道和關係把價值交到客戶手中；業務、資源與夥伴承接交付；收入和成本說明價值如何被獲取及其代價。檢查對應關係，不為湊齊關係製造材料裡沒有的內容。

## 經典佈局

```text
┌──────────┬──────────┬──────────┬──────────┬──────────┐
│          │ 關鍵業務 │          │ 客戶關係 │          │
│ 重要合作 ├──────────┤ 價值主張 ├──────────┤ 客戶細分 │
│          │ 核心資源 │          │ 渠道通路 │          │
├──────────┴──────────┴────┬─────┴──────────┴──────────┤
│        成本結構          │        收入來源           │
└─────────────────────────┴───────────────────────────┘
```

標題區包含物件、範圍／階段、日期／版本及一句話概括。日期使用任務所在時區。畫布預設橫版，資訊密度優先於強行保持某個長寬比。每條狀態標籤與來源編號都可見；完整來源摘要保留在 JSON，避免在卡片頁尾堆滿訪談原文。
