# 共同品味底線

四種模具可以完全不同，但都必須讓「判斷」先於「裝飾」。

## 1. 視覺必須有工作

每一幅生成圖都要能回答：它讓讀者看見了哪一句話單靠文字不容易看見的東西？

- 有動作、有物件、有衝突；少用抽象光線、漂浮幾何和通用 AI 意象。
- 不因版面空就補圖。刪掉圖片後理解不變，這張圖就不該生成。
- 同一成品內不要重複同一隱喻、同一鏡頭或同一資產。
- 原文圖片是證據時，保真引用並標註來源；不能重生成後冒充原圖。
- 知識講解中的具體物件要有判別工作：讀者能指出哪個特徵使它屬於該概念、哪個條件改變結果。類比可幫助理解，但不充當目標領域的例項或證據。

## 2. 圖文各司其職

- 生成圖：人物、物件、場景、動作、空間關係、情緒張力。
- HTML/CSS：標題、正文、數字、公式、座標、標籤、箭頭、批註、來源。
- 圖中禁止可讀文字、字母、數字、Logo、水印、偽標籤和偽介面。
- 每個圖片槽都有具體 `alt`，描述圖中動作及其與正文的關係；禁止寫「配圖」。

## 3. 版式不要平均

- 禁止把內容機械切成三等分、四等分或一排相同卡片。
- 留白跟著敘事節奏走：轉折與結論可以放大，鋪墊應收緊。
- 一頁只有一個主視覺焦點；其他元素服務它。
- 圖片構圖必須提前給標題區、正文區或標註區留安全區，不能事後壓字補救。

## 4. 字與顏色

- 停用 Inter；優先 mode 指定字族與中文系統字族。
- 正文不用純黑 `#000000`，用暖黑或深灰。
- 主色要有角色，不把五六種高飽和顏色平均分給模組。
- 不用漸變、厚陰影、玻璃擬態、發光邊框製造「高階感」。
- 字號按 1080px 成品檢查，不用桌面網頁字號直接截圖。

## 5. 中文與事實

- 判斷、機制與適用條件隨論證自然展開，不據此製造固定欄目或尾部免責宣告；少寫「賦能、重塑、構建、深度、全新」等空詞。
- 不編數字、引語、機構、人名或來源。
- 不把解釋寫進生成圖，再依賴模型拼字。
- 每句默唸一遍：像中文口語或成熟書面語，不像翻譯腔與模板腔。
- 收尾停在內容自身的最後一句，之後只接署名與來源。製作範圍、驗收狀態和泛泛的閱讀提醒放在交付回覆，不追加到讀者正在讀的內容裡；全文模式保留原稿本有文字。

## 6. 禁止偽完成

- 不使用遠端隨機圖、佔位圖、假 logo、壞鏈圖片。
- 不用 CSS 圖示或向量圖冒充已經完成的概念主視覺。
- 圖片工具不可用、語義錯誤或含偽文字時，最多定向重生兩次；關鍵圖仍失敗就阻斷。
- 能開啟 HTML 不算完成；必須得到 PNG 並做畫素讀回。

## 7. 最終視覺檢查

- 視覺層級：三秒內能找到標題、主判斷和下一步閱讀方向。
- 語義：每圖能回指一個源判斷，沒有通用裝飾圖。
- 影像：無偽文字、無品牌汙染、無主體裁切、無重複資產。
- 文字：無溢位、遮擋、過小字號、孤行或來源漂移。
- 長圖：整圖一次，頂部/中段/底部重疊切片覆蓋全部高度。
