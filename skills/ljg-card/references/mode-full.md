# 模具：全文（-f）

`-f` 把完整文稿鑄成一張可連續閱讀的長 PNG。它的設計物件是版式，不是文字：原稿中的可見字句逐塊只出現一次，字元與先後順序不變；標題、強調、留白與字重只改變讀者怎樣看見它們。

執行時依次 Read `references/taste.md` 與 `assets/full_template.html`。預設生成圖數量為 `0`。原稿自帶圖片時，補讀 `references/image-generation.md` 的資產身份與來源保真部分；圖片仍是 `source`，不得重生成、重繪或換成概念配圖。

## 讀者承諾

- **第一眼：**看見純白頁面、深黑正文、剋制灰階和非平均留白形成的清楚閱讀秩序。
- **開始讀：**標題、正文、引用、列表、程式碼與腳註各有清楚層級，但沒有額外導語、金句卡或解釋框打斷作者。
- **讀到底：**能逐段回到原稿核對，沒有少字、改字、調序、合併、重複或補寫。

## 原文邊界

以下變化屬於排版，允許發生：

- 把原稿已有標題、二三級標題對映到 `h1`、`h2`、`h3`。
- 把原稿已有粗體、斜體、引用、列表、程式碼、表格、腳註對映到對應 HTML 語義標籤。
- 給某個原稿塊新增 `.full-key`、`.opening` 等樣式類，改變字號、字重、顏色、行距、邊線或上下留白。
- 為 HTML 安全跳脫字元，只要瀏覽器讀回的 `textContent` 與原稿塊完全相同。

以下變化屬於改稿，禁止發生：

- 摘要、潤色、糾錯、改標點、同義改寫、刪節、合併段落、調換順序。
- 從正文抽一句再複製成題記、金句、側欄或結尾大字。
- 原稿沒有標題時補標題；沒有導語、小結或過渡句時補寫這些內容。
- 為了版面整齊截短列表、表格、程式碼、腳註或來源說明。
- 用 CSS `order`、浮動或定位讓視覺閱讀順序偏離 DOM 與原稿順序。

原稿已有標題只出現一次：它可以成為大標題，但不能在正文再重複。原稿沒有顯式層級時，可以給現有文本塊不同視覺權重，不能以設計判斷改寫其文字身份。

## 來源鎖與原文塊賬本

渲染前鎖定一份本地來源：本地檔案直接記錄路徑與 SHA-256；URL 正文或貼上文本先原樣儲存到本任務 `/tmp` 目錄，再記錄 SHA-256。來原始檔在交付前不得變化。

建立 `source-ledger.json`：每一項對應一個最終可見文本塊。塊內文字逐字元保留，塊的陣列順序就是閱讀順序。

賬本只做一種規範化：把 `CRLF` / `CR` 行尾轉成瀏覽器 `textContent` 使用的 `LF`。不得 trim、摺疊連續空格或改全半形；`source_sha256` 始終針對未規範化的原始來原始檔。

```json
{
  "version": 1,
  "source_sha256": "<64 lowercase hex characters>",
  "blocks": [
    { "id": "b001", "text": "原稿標題" },
    { "id": "b002", "text": "第一段原文，標點與空格都保留。" }
  ]
}
```

HTML 中每個文本塊使用同一個 ID：

```html
<main class="full-document">
  <h1 data-source-block="b001">原稿標題</h1>
  <p data-source-block="b002">第一段原文，標點與空格都保留。</p>
</main>
```

- `data-source-block` 只放在葉子文本塊上，不能巢狀。
- 行內 `strong`、`em`、`code`、連結可以位於塊內；它們的合併 `textContent` 仍須與 ledger 完全一致。
- 列表逐項登記；表格逐個表頭與單元格登記；程式碼塊、圖注和腳註各自登記。
- `.full-document` 內所有可見文字都必須屬於某個原文塊。純佈局容器、分隔線與無文字來源圖片可以不登記。
- 來源圖片使用本地絕對路徑、原始比例和語義化 `alt`；原稿有圖注時，圖注本身是一個原文塊。

## 全文校驗工具

填完模板、截圖之前執行：

```bash
bun assets/verify-full-text.ts \
  /tmp/<task>/source-ledger.json \
  /tmp/<task>/full.html \
  /tmp/<task>/source.txt
```

工具同時核對來源 SHA-256、塊 ID、塊數量、字元、順序、重複、巢狀塊，以及 `.full-document` 中未登記的可見文字。任一項不一致就停止；不能用人工目測覆蓋失敗。

驗收反例固定為四類：改單字、調序、漏塊、重複塊。四類中的任意一種都必須讓校驗工具退出非 0。

## 版式母語

- `-f` 是白底黑字的長文閱讀面：畫布固定為純白 `#FFFFFF`；普通正文為深中性黑 `#171717`；輔助文字為 `#525252`；弱資訊為 `#7A7A7A`；規則線為 `#E5E5E3`。暗硃紅 `#A74432` 只承擔少量章節分隔與強調，不成為正文主色。
- title、headline、章節標題、正文、強調、圖注、表頭與署名統一優先使用本機已安裝的 `KingHwa_OldSong`。若本機沒有該字型，瀏覽器自動回退：正文落到 `Songti SC`、`STSong`、`Noto Serif CJK SC`、`serif`；標題類文字落到 `PingFang SC`、`Hiragino Sans GB`、`Microsoft YaHei`、系統 sans。不得聯網下載、臨時安裝或通過遠端 `@font-face` 補齊。`code`、`pre` 與 Footer 來源行保留等寬字型，這是字元對齊有語義的唯一例外。
- 1080px 成品的普通正文不小於 `40px`，行高為 `1.9`，有效正文寬度約 `896px`。正文段距保持 `36px`；章節上方留白明顯更大。鋪陳段落可以收緊，不能通過縮小字號或壓縮行距減少圖片高度。
- 標題層級為 `80/54/44px`，開篇與重點段為 `44px/1.9`。約 390px 手機顯示寬度下，40px 正文約等效 14.4px；驗收時同時看手機寬度預覽與原尺寸切片。長圖增高是放大文字的正常代價，不能為壓縮高度縮字。
- `strong` 與 `.full-key` 用字重、暗硃紅細線或淺色平面強調；不使用高亮熒光、漸變、發光、玻璃擬態或厚陰影。
- 引用用細豎線和更松的行距；程式碼與表格用等寬字和淺中性灰平面；列表與引用保持 `40px/1.9`，不能降成小字；表格為 `34px`，程式碼塊與腳註為 `32px`，圖注為 `30px`，這些輔助層級行高不低於 `1.7`。
- 版面不放裝飾插圖、偽印章、英文大字水印、自動編號或模板口號。審美來自比例、字與空白。

`assets/full_template.html` 已提供固定視覺系統。`{{CUSTOM_CSS}}` 只用於適配特殊原稿結構，不能覆蓋原文邊界、把正文縮到不可讀，或引入遠端資源。

字型完成態看瀏覽器實際使用結果，不只看 CSS 字型棧：本機已安裝 `KingHwa_OldSong` 時，普通正文、`h1` title 與 `h2` headline 的 platform font 都應解析到它；未安裝時，正文和標題分別落到各自的本地預設棧即可繼續。缺失首選字型本身不是失敗，遠端取字型才是失敗。

## HTML 表面

模板的正文入口只有一個：`{{DOCUMENT_HTML}}`。完整原稿按原順序全部進入 `.full-document`；Footer 位於正文區之外，不參與原文塊校驗。

可用語義表面：

- `h1`、`h2`、`h3`、`p.opening`
- `strong`、`em`、`.full-key`
- `ul`、`ol`、`blockquote`
- `pre`、行內 `code`
- `table`、`caption`、`th`、`td`
- `.source-figure`、`figcaption`
- `.footnotes`、`.footnote`、`.section-break`

替換 `{{DOCUMENT_HTML}}`、`{{CUSTOM_CSS}}`、`{{LOGO}}` 與 `{{SOURCE_LINE}}` 後，HTML 中不能殘留佔位符。

## 截圖與驗收

```bash
bun assets/capture.ts /tmp/<task>/full.html <final.png> 1080 1600 fullpage
```

交付條件：

- 全文校驗 exit 0，報告的 expected/actual block 數相同。
- 來原始檔的交付後 SHA-256 與賬本記錄相同。
- 生成圖數量為 `0`；所有原稿圖片均為本地 `source` 資產，完整、未裁壞、來源身份明確。
- DOM 無殘留佔位符、未登記文字、遠端字型、遠端圖片、橫向溢位或小於模板腳註等級的正文。
- 字型檢查分別報告普通正文、title 與 headline 的實際 platform font：本機有 `KingHwa_OldSong` 時三者都使用它；沒有時報告各自命中的預設本地字型，不偽稱首選字型已生效。
- 計算樣式確認畫布為 `#FFFFFF`、普通正文至少 `40px/1.9`，正文與背景對比度高於 `15:1`；只看模板原始碼不算完成。
- PNG 寬 1080px、8-bit RGB；整圖檢查能看清層級與節奏，重疊切片覆蓋全部高度並逐段核對無截斷、遮擋、孤行或表格越界。
- 若全文高度超過單張 PNG 的可靠渲染上限，停止並說明邊界；未經使用者同意，不得以截斷圖片冒充全文，也不得擅自改成交付多張。
