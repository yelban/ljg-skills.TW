# ljg-book 材料與檢查記錄

這是研究與核對記錄，不是正文提綱。冒號前欄位名由指令碼讀取，保留寫法。欄位填寫只能證明記錄存在，不能證明解釋正確或文章好讀。沒有材料時如實寫清，不以推測補齊經歷。

## 材料邊界

- 覆蓋合同版本：3
- 材料等級：{完整拆書 / 初拆 / 假設版}
- 主要材料：{實際讀過的版本、路徑或來源；全書閱讀範圍與未讀部分}
- 能支援到：{可以解釋哪些內容；不能支援哪些內容；若需補材料，記錄結果}
- 材料能否支撐認識更新路徑：{是 / 否——原有理解、壓力與變化是否有依據；材料不足時不升級為完整拆書}

## 全書怎樣構成整體

核心理解、部分關係和作者關切在這裡各記錄一次；不要在不同欄裡反覆改寫同一句總論。多線作品按實際內容說明，允許並列、對照或無法統一的矛盾。

- 這是什麼型別或形態的書：
- 起點、主要變化與終點：{具體物件或人物、重要過程、結尾與未決部分}
- 核心理解：{最初怎樣理解；什麼內容迫使補充或改變；修訂後怎樣看}
- 各部分怎樣相連：{不可省主線及各自作用；依賴、分工、因果、對照或限制；不能只寫共同主題}
- 作者最想糾正或保留什麼：{從原書取捨與發展推知，並給出依據；不虛構作者心理}
- 正文必須出現的整書錨點：{正文選用、具有材料依據的具體短語；完整至少3個，部分至少1個，用｜分隔；不以增加數量證明完整}

## 正文沿哪些線索展開

每行記錄一個持續展開的問題、人物、關係或模型。一個線索可以經過多個階段、承擔不同作用；不為每個概念另建一個例子。換場確有必要時，說明承接的關切及新增作用，不強守同一個物件，也不限制線索數。

- [thread] 名稱：｜起點：｜關鍵推進：｜前後變化：｜換場理由：｜依據與邊界：

「前後變化」寫出原來和後來的實際判斷、條件或含義；無行動結果時不要編造。自擬情景與原書事實在「依據與邊界」中分清。正文讓這些關係展開，不照著欄位報幕。

## 共同解釋與圖表

- 是否存在全書生成器：{是 / 否——是否確有能解釋多處轉折的關係；無則不湊公式}
- 全書生成器：{若存在，用普通話寫清它怎樣起作用；無則說明}
- 生成器怎樣貫穿至少兩個遠距轉折：{同一關係怎樣解釋兩處變化；給出一個相近情況怎樣遷移；無則說明}
- 生成器在哪些條件、範圍或層級失效：{前提、反例或不能回答的問題；無共同解釋則說明不能統一之處}
- 是否需要視覺表示：{是 / 否——為什麼文字足夠或不夠}
- 使用圖表的位置與目的：{需要時逐一記錄所表示的關係、圖後解釋與具體執行；不需要時說明}

## 來源與取捨

完整拆書保留以下四類來源證據和至少5項候選材料。候選可以是方法、事件、關係或主線，不等於正文需要相同數量的場景。刪去一個例子，仍要確認它承擔的必要解釋沒有丟失。

- [starting-point] 位置：｜證據：
- [pressure] 位置：｜證據：
- [revision] 位置：｜證據：
- [boundary] 位置：｜證據：

- [candidate] 名稱：｜位置：｜解決的問題：｜與其他部件的關係：｜決定：｜刪除測試：

- [candidate] 名稱：｜位置：｜解決的問題：｜與其他部件的關係：｜決定：｜刪除測試：

「決定」使用「保留」「合併」「刪除」。初拆與假設版只記錄材料支援的證據，不為滿足完整拆書欄位捏造整書。沒有依據的 thread、candidate 或證據佔位行應刪除；未能確定的理解寫明未知，不把空模板作為已經提供的記錄。

- 反證與取捨：{當前解釋會遺漏什麼，競爭解釋或邊界是什麼，怎樣處理；全書有何重要內容未展開及理由}

## 成品閱讀檢查

先給評估者成品，再把其實際回答寫在這裡；不要把這裡的答案交給評估者。來源忠實度另行回查原文。記錄具體閱讀位置和結果，不只寫PASS。

- 整書複述與關係重建：{型別、物件、起點變化終點、必需主線及分工、未決問題；共同解釋與遷移；支撐複述的正文展開，不能僅摘抄概況段；評估者和檢查範圍}
- 閱讀斷點與修訂：{哪裡缺了關係、過早換物件或引入名稱，或退到書籍簡介與寫作說明；切換的實質必要性；哪兩段顯示實際理解變化；怎樣修訂及復讀結果；未發現時記錄依據}
- 遮住末節後能否理解作者關切：{正文哪些發展已使關切可見；有沒有靠末節補進新道理或重複收束}
- 正文中哪兩個相隔較遠的轉折共同托住它：{它指末節的意思；指出兩處及其共同作用，不另寫一份精神核心}
